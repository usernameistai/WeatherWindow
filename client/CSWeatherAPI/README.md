A high-fidelity meteorological tracking grid and geospatial matrix. Engineered to intercept macro-climatic atmospheric streams, compute immediate environmental safety threats, and project interactive county-level telemetry.

---

## 📑 OPERATIONAL DIRECTIVES

### 01. ENVIRON-THEME SHIFTING (THE "DUAL-AXIS" VIEWPORT)
The UI acts as a true window into the climate vector. Toggle the specialized theme array to re-render the aesthetic profile based on your operational environment.
- **Matrix Filters:** Seamlessly toggle between full City Scape or Countryside perspectives.
- **Photonic Overrides:** Deploy light-mode or dark-mode overrides depending on ambient workspace visibility.
- **Bookmark Hub:** Quick-access arrays sit directly beneath the navigation baseline to monitor frequently intercepted target cities.

### 02. ATMOSPHERIC CRITICAL METRICS & EARLY WARNINGS
The primary telemetry stack decodes comprehensive geographic coordinates alongside granular atmospheric readings.
- **Telemetry Breakdown:** Captures localized Temp, Feels-Like variables, Lat/Long grid positioning, Humidity, and precise Wind Vectors.
- **The UV Threat Matrix:** Tracks real-time UV Index limits paired with dynamic icon rendering and environmental safety status scripts.
- **Anomalous Countdown Timer:** Features a persistent automated ticker counting down to the exact second a severe or hazardous weather alert breaches the target coordinate boundary.

### 03. 5-DAY PROJECTIONS & MATHEMATICAL VARIANCE
Deep-dive forecasting logic streams data into multi-axis visual representation models.
- **The Recharts Matrix:** Translates a 5-day predictive payload array directly into responsive SVG vector lines.
- **Calculated Thresholds:** Computes absolute Minimum and Maximum historical boundaries directly from the raw array metrics to clamp the upper and lower bounds of the visualization frame.

### 04. GEOSPATIAL COUNTY INTERCEPT (THE "D3" MAP GRID)
Features a highly responsive, vector-mapped geoJSON structural overlay of the United Kingdom.
- **Desktop Diagnostics:** Hovering over specific regional coordinates activates an immediate lookup query for that county's primary urban hub.
- **Mobile Touch Intercept:** Touch-focus listeners scale gracefully onto mobile devices, allowing operators to execute instant regional overrides via tactical display presses.

## 🛠️ TECH SPECS
- **Core Engine:** React 19, TypeScript, Vite
- **Global Variable Hub:** Zustand (Orchestrates synchronized global states for coordinate favorites, active light/dark environments, and UI viewport switches)
- **Geospatial Processing:** D3.js and TopoJSON/GeoJSON custom vectors
- **Visualization:** Recharts Multi-Line Predictive System
- **Styling Architecture:** Tailwind CSS paired with Framer Motion for micro-interactive focus states
